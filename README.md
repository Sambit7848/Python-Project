## 📌 Project Overview

**Customer Segmentation Analysis** is a simple Python-based data analysis project that categorizes customers based on their **total spending** and **purchase frequency**.

The project uses **rule-based segmentation** instead of machine learning, making the analysis simple, transparent, and easy to understand.

It also includes an **interactive Streamlit dashboard** for exploring customer segments and analyzing customer behavior.

---

## 🎯 Project Objectives

- Analyze customer spending behavior
- Analyze customer purchase frequency
- Categorize customers into meaningful segments
- Visualize customer behavior
- Explore individual customer segments interactively
- Export the segmentation results as a CSV file

---

## 🧠 Segmentation Logic

Customers are categorized using simple Python-based conditions:

| Segment | Description |
|---|---|
| 🟢 **High Value Customer** | Higher spending and frequent purchases |
| 🔵 **Regular Customer** | Moderate spending and purchase frequency |
| 🟠 **Low Value Customer** | Lower spending and fewer purchases |

> **Note:** The segmentation is completely rule-based and does not use machine learning.
